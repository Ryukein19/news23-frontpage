The world's news of Monday 23 November 2026 in one image — a front-page grid.

Lead: **COP31 collapses with no deal** — the longest climate summit on record
ends without agreement as the EU rejects a text silent on fossil fuels.
Also: Ukraine sinks the Russian corvette Merkury off Libya with 7 sea drones;
Nvidia soars 31% as Jensen Huang returns as chief executive; 24 are killed
in a sweets-factory fire in Indonesia; India gives Nepal a $1.62bn rebuilding
package; Russian strikes kill 15 in the Kyiv region.

`main.py` (Python 3.13 stdlib only) draws the 1024×1024 front page with a
built-in 5×7 bitmap font and writes it to `/output/entry.png`. It is fully
deterministic — every run writes identical bytes. All facts are verified from
two or more independent sources.
